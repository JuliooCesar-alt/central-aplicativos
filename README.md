Central de Aplicativos
Ferramenta desenvolvida para facilitar a instalação e atualização de aplicativos no Windows.
Funcionalidades
- Aplicativos organizados por categorias.
- Seleção de múltiplos programas.
- Download e instalação automatizados.
- Acompanhamento do processo de instalação.
- Catálogo de aplicativos atualizado periodicamente.
Compatibilidade
Windows 10 e Windows 11.
Projeto em desenvolvimento e manutenção contínua.

Desenvolvido para auxiliar na padronização e manutenção de ambientes Windows.
